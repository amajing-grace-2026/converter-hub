Kenalan dulu

Amajing Converter adalah kumpulan alat untuk mengubah dan merapikan file langsung dari browser. Tidak perlu daftar akun dan tidak perlu memasang program apa pun.

File kamu tetap di perangkatmu. Semua proses berjalan di dalam browser, di laptop atau HP kamu sendiri. File tidak dikirim ke server mana pun, jadi aman juga untuk dokumen pribadi atau kantor.

Cara memakai

  1. Pilih alat yang kamu perlukan dari menu. Di laptop menunya ada di kiri; di HP menunya ada di atas dan bisa digeser ke samping.
  2. Klik kotak bergaris putus-putus untuk memilih file, atau tarik file dari folder langsung ke kotak itu.
  3. Atur pilihan bila perlu, tekan tombol biru (Konversi, Kompres, Gabung, dan lain-lain), lalu tekan Unduh. Hasilnya masuk ke folder Downloads.

Khusus laptop

Aktivasi laptop ASUS

Di laptop, Amajing Converter khusus untuk laptop ASUS. Saat pertama dibuka, muncul layar Aktivasi. Aktivasi cukup sekali per laptop. Di HP dan tablet, aplikasi langsung bisa dipakai tanpa aktivasi.

  1. Klik kanan tombol Start (logo Windows) di pojok kiri bawah, lalu pilih Terminal atau Windows PowerShell.
  2. Di layar Aktivasi, tekan 📋 Salin perintah. Kembali ke jendela Terminal, klik kanan untuk menempel, lalu tekan Enter. Tidak ada tulisan yang muncul, tetapi serial number laptop sudah tersalin.
    Perintahnya: (Get-CimInstance Win32_BIOS).SerialNumber | Set-Clipboard
  3. Kembali ke layar Aktivasi, klik kotak Serial number, tekan Ctrl+V, lalu tekan Aktifkan.

Hasil aktivasi

✓ TerverifikasiAplikasi langsung terbuka dan tetap aktif, walaupun browser ditutup atau laptop dimatikan.
⏳ Sedang diverifikasiSerial belum ada di data kami. Aplikasi tetap bisa dipakai selama masa tunggu 30 menit, dan dicek ulang otomatis setiap 5 menit selama ada internet.
Belum terdaftarMasa tunggu sudah habis dan serial tetap belum terdaftar. Hubungi toko tempat kamu membeli laptop.
Sudah terpakaiSerial itu sudah diaktifkan di perangkat lain. Satu serial number hanya untuk satu laptop.
Satu serial = satu laptop. Aktivasi tersimpan di browser yang dipakai saat aktivasi. Kalau nanti ganti browser, laptop di-reset, atau data browser terhapus, hubungi toko supaya serialnya dibuka kembali, lalu ulangi langkah di atas.
Butuh internet saat aktivasi. Setelah aktif, aplikasi tetap bisa dipakai walaupun sedang tidak ada internet.
Bagian 1

Audio & Video

🎵 MP4 → MP3

Mengambil suara dari video menjadi file MP3, misalnya lagu atau rekaman rapat.

  1. Pilih satu atau beberapa video sekaligus (MP4, M4A, MOV, WEBM).
  2. Pilih Kualitas. Setiap file langsung diproses.
  3. Tekan Unduh MP3 per file, atau Unduh semua.
Kualitas128 kbps = file kecil · 192 kbps = standar · 320 kbps = terbaik untuk musik

🎞️ Video → GIF

Membuat GIF bergerak dari potongan video, misalnya untuk stiker atau presentasi.

  1. Pilih satu video. Videonya akan muncul dan bisa diputar.
  2. Tentukan Mulai dan Selesai (dalam detik). Cara mudahnya: putar video sampai bagian yang diinginkan, lalu tekan ⏱ dari video.
  3. Atur FPS, lebar, dan pengulangan, lalu buat GIF dan tekan Unduh GIF.
FPSJumlah gambar per detik. Makin tinggi makin halus, tapi file makin besar. 12 sudah pas.
Lebar240–800 px. 480 px cocok untuk kebanyakan keperluan.
UlangTerus-menerus, atau diputar sekali saja.
Tips: GIF paling bagus untuk potongan pendek (maksimal sekitar 15 detik). Potongan yang panjang membuat file sangat besar.

📦 Kompres Video

Memperkecil ukuran video supaya muat dikirim lewat WhatsApp atau email. Hasilnya selalu MP4.

  1. Pilih satu video (MP4, MOV, WEBM, MKV).
  2. Pilih Cara: isi target ukuran dalam MB, atau pilih tingkat kualitas.
  3. Atur resolusi, FPS, dan suara bila perlu, tekan Kompres, lalu Unduh MP4.
Target ukuranContoh: isi 16 MB agar muat di WhatsApp.
ResolusiAsli, 1080p, 720p, 480p, 360p. Makin kecil, makin kecil pula filenya.
SuaraNormal, Hemat, atau Hapus suara.
Perlu Chrome/Edge terbaru. Video panjang butuh waktu lebih lama, jadi biarkan tab tetap terbuka sampai selesai.
Bagian 2

Gambar

🖼️ JPG / PNG / WEBP termasuk HEIC

Mengubah format gambar sekaligus memperkecil ukurannya. Alat ini juga bisa mengubah foto HEIC dari iPhone atau Samsung menjadi JPG agar bisa dibuka di mana saja.

  1. Pilih satu atau banyak gambar sekaligus (JPG, PNG, WEBP, HEIC/HEIF, GIF, BMP, AVIF).
  2. Pilih format tujuan di Jadi, lalu atur kualitas dan ukurannya. Hasilnya langsung diperbarui setiap kali pengaturan diubah.
  3. Tekan Unduh per gambar, atau Unduh semua.
JadiJPG = foto, paling umum · PNG = gambar dengan latar transparan atau tulisan tajam · WEBP = paling kecil, cocok untuk web
Kualitas10–100%. 85% sudah tidak terlihat bedanya dengan yang asli.
UkuranAsli, atau batasi sisi terpanjang (3840 sampai 512 px). 1920 px cocok untuk dikirim lewat chat.
Foto iPhone (.heic): pilih Jadi → JPG. Membuka HEIC pertama kali butuh beberapa detik.
Bagian 3

Dokumen

📝 Word → PDF

Mengubah dokumen Word menjadi PDF. Ada dua cara:

A. Buka file .docx

Tekan 📂 Buka file .docx, atau tarik file ke kertas putih. Gambar ikut terbawa, tetapi warna dan jenis huruf bisa sedikit berbeda.

B. Salin-tempel dari Word

Di Word tekan Ctrl+A lalu Ctrl+C. Klik kertas putih di aplikasi dan tekan Ctrl+V.
  1. Rapikan bila perlu dengan toolbar (tebal, judul, daftar, rata, ⤓ Hal untuk pindah halaman).
  2. Atur kertas (A4, F4/Folio, Letter), arah, margin, dan huruf. Isi Nama file.
  3. Tekan Simpan sebagai PDF. Di jendela cetak pilih Tujuan → Simpan sebagai PDF, lalu Simpan.
Tips: buka Setelan lainnya di jendela cetak dan matikan Header dan footer supaya tanggal dan alamat web tidak ikut tercetak. Tulisanmu tersimpan otomatis, jadi tidak hilang meskipun tab tertutup.

📄 PDF → Word

Mengubah PDF menjadi file Word (.docx) yang bisa diedit. Hasil terbaik didapat dari PDF yang dibuat dari komputer, bukan hasil scan.

  1. Pilih satu file PDF.
  2. Pilih Mode, lalu tekan Konversi ke Word dan Unduh Word.
Tata letak persisPilihan utama. Tampilan sama seperti PDF, dan teksnya tetap bisa diedit. Cocok untuk surat, formulir, atau brosur.
Alur teks biasaTeks mengalir seperti dokumen Word biasa. Enak untuk mengedit tulisan panjang, tetapi gambar dan tabel tidak ikut.
Gambar sajaSetiap halaman menjadi gambar. Tampilannya 100% sama, tetapi tidak bisa diedit.
PDF hasil scan berisi foto halaman, bukan teks, sehingga teksnya tidak bisa diedit.

🗂️ Gambar → PDF

Menyatukan beberapa foto menjadi satu PDF, misalnya foto KTP, ijazah, atau nota.

  1. Pilih gambar-gambarnya (bisa ditambah kapan saja, termasuk HEIC).
  2. Atur urutan dengan ↑ ↓, hapus dengan ✕, atau tekan Urutkan A–Z.
  3. Pilih kertas, arah, margin, dan kualitas, isi nama file, lalu buat PDF dan tekan Unduh PDF.
KertasA4, F4/Folio, Letter, atau Sesuai gambar (tanpa tepi putih).
KualitasTinggi, Sedang, atau Kecil (hemat). Pilih Kecil untuk upload berkas yang ukurannya dibatasi.

🖼️ PDF → Gambar

Mengubah setiap halaman PDF menjadi gambar.

  1. Pilih satu PDF, lalu pilih format (PNG, JPG, WEBP) dan resolusi.
  2. Isi Halaman (misalnya 1-3,5), atau kosongkan untuk semua halaman. Tekan Konversi.
  3. Unduh per halaman, atau Unduh semua (ZIP).
Resolusi72 dpi (layar) · 150 dpi (sedang) · 200 dpi · 300 dpi (untuk dicetak)

🔗 Gabung PDF

Menyatukan beberapa file PDF menjadi satu.

  1. Pilih beberapa PDF. File bisa ditambah lagi kapan saja.
  2. Atur urutan dengan ↑ ↓. Di kotak samping tiap file, isi halaman yang diambil (misalnya 1-2), atau kosongkan untuk semua halaman.
  3. Isi nama file, gabungkan, lalu tekan Unduh PDF.

✂️ Pisah PDF

Memecah satu PDF menjadi beberapa file, atau mengambil dan membuang halaman tertentu. Kualitasnya tidak berubah.

  1. Pilih satu PDF, lalu pilih Cara dan isi kotak di sebelahnya.
  2. Periksa pratinjau pembagian di bawahnya, tekan Pisah, lalu unduh per file atau Unduh semua (ZIP).
Setiap halamanSetiap halaman menjadi satu file.
Per rentangContoh 1-3, 4-6, 7- → tiga file.
Setiap N halamanContoh 2 → setiap 2 halaman menjadi satu file.
Ambil halamanContoh 1, 3, 5-7 → satu file berisi halaman itu saja.
Hapus halamanContoh 2, 4 → satu file tanpa halaman 2 dan 4.

🗜️ Kompres PDF

Memperkecil ukuran PDF untuk upload berkas atau email. Paling efektif untuk PDF hasil scan atau yang banyak fotonya.

  1. Pilih satu PDF, lalu pilih Mode dan Tingkat.
  2. Tekan Kompres. Ukuran sebelum dan sesudah akan ditampilkan. Tekan Lihat untuk memeriksa hasilnya, lalu Unduh PDF.
Pertahankan teksPilihan utama. Hanya foto di dalam PDF yang dikecilkan, sehingga teks tetap tajam dan bisa disalin.
Paling kecilSetiap halaman diubah menjadi gambar. Filenya paling kecil, tetapi teks tidak bisa disalin lagi.
TingkatRingan (kualitas tinggi) · Sedang · Kuat (file terkecil)

🧮 Kalkulator

Kalkulator sehari-hari dengan format angka Indonesia (titik untuk ribuan, koma untuk desimal, misalnya 1.234,5).

  • Bisa dipakai dengan keyboard: angka, + − * /, Enter untuk hasil, Backspace untuk menghapus satu angka, dan Esc untuk menghapus semua.
  • % bekerja seperti kalkulator HP. Contoh: 200.000 − 10% = 180.000.
  • 📋 Salin hasil menyalin angka untuk ditempel di chat atau Excel.
  • Riwayat menyimpan hitungan sebelumnya. Klik salah satu untuk memakai hasilnya lagi.

Bagian 6

Tanya jawab

Apakah file saya di-upload?

Tidak. Semua proses terjadi di perangkatmu sendiri. Kamu bahkan bisa memutus internet setelah alatnya terbuka.

Hasil unduhan ada di mana?

Di folder Downloads (Unduhan) pada laptop atau HP kamu.

Prosesnya lama atau macet

File besar (video panjang, PDF ratusan halaman) memang butuh waktu. Biarkan tab tetap terbuka dan jangan pindah ke aplikasi lain di HP. Kalau tetap gagal, tutup tab lain yang berat, lalu coba lagi.

Ada alat yang tidak jalan

Pastikan kamu memakai Chrome atau Edge versi terbaru. Kompres Video membutuhkan fitur browser terbaru, sehingga tidak semua browser lama bisa menjalankannya.

Hasil PDF → Word berantakan

Coba mode lain. Pakai Tata letak persis untuk tampilan yang sama dengan PDF, atau Alur teks biasa untuk mengedit tulisan panjang. PDF hasil scan memang tidak bisa diubah menjadi teks.

Punya saran atau menemukan kesalahan?

Tekan 💬 Kirim masukan di bagian bawah aplikasi. Setiap masukan dibaca.
